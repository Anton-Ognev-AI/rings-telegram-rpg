# Project Template for Claude Code

Минимальный и эффективный шаблон для управления контекстом и задачами при работе с Claude Code.

## Как использовать
1. Скопируйте содержимое этой папки в новый проект.
2. Отредактируйте `PROJECT_STATE.md`, указав стек технологий и цель.
3. Добавьте первую задачу в `TASKS.md`.

## Структура
- `CLAUDE.md`: Инструкции для AI.
- `PROJECT_STATE.md`: Текущее состояние (Источник правды).
- `TASKS.md`: Список задач.
- `DECISIONS.md`: Журнал решений.
- `/skills`: Папка для кастомных инструкций.

## Связь с AI
Этот проект управляется по протоколу CLAUDE.md.
