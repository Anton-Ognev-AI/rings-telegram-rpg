## Delivered

- opaque HMAC callback tokens bounded to 64 bytes and actor-bound context hashes;
- precomputed deterministic resolutions persisted for every visible option;
- P01-informed Ukrainian cards with encounter-specific headings, separate observations, no pre-choice
  threshold leak, and exact post-choice stat/HP/damage/healing/XP breakdown;

  layouts plus final exchange details and next-day 09:00 hook;
- pure `/start`, expedition, resume, privacy, deletion-confirmation, duplicate/stale callback routing;
- leased outbox worker with sent/retry/dead/delivery-unknown/superseded handling and safe edit retry;
- forward-only migration 010 with a service-only, owner-bound render-repair RPC: concurrent requests
  coalesce, only a known canonical message may be edited, and delivery-unknown can never become a
  blind resend;
- `/resume`, cached choices, active stale choices, and terminal stale choices request a canonical
  edit; callback acknowledgement is best-effort and cannot block the durable mutation;
- fetch-based Supabase RPC and Telegram Bot API adapters whose errors do not expose credentials;
- thin `tg-webhook`, `outbox-worker`, and `day-publish-reset` Edge roots. Only `tg-webhook` has
  `verify_jwt = false`, and it verifies the Telegram secret before parsing. The two privileged
  internal roots retain JWT verification and additionally require a dedicated internal secret
  before constructing any service-role adapter.

Production-shaped handling creates the immutable run snapshot from authoritative persisted player
stats. The synthetic developed solo snapshot exists only as an injected E2E fixture. Tutorial
progression, teacher rescue, items, rings, friends, and XP spending remain later phases.
